# Edgar Rodriguez Portfolio

Portafolio profesional de Edgar Rodríguez, **Software Developer Jr**, construido con React, Vite, Tailwind CSS y Framer Motion.

## Objetivo

Mostrar experiencia real en desarrollo web, sistemas internos, automatización, integración de herramientas y proyectos aplicados a negocio, con una línea visual **dark premium** (acentos índigo/violeta, glass UI, bordes suaves y fondos con degradados sutiles).

## Últimos Cambios Realizados

### Mejora general de estructura visual
- Se eliminaron los badges/eyebrows innecesarios en secciones como Hero, Experience, Projects, Stack y Contact para lograr una interfaz más limpia y profesional.
- Se ajustó la jerarquía visual de las secciones para que el contenido principal tenga más protagonismo.
- Se mantuvo una línea visual dark premium con acentos índigo/violeta, glass UI, bordes suaves y fondos con degradados sutiles.

### Actualización del Hero
- Se actualizó el enfoque principal del Hero de un perfil limitado a Backend/Fullstack hacia un perfil más amplio como **Software Developer Jr**.
- Se agregaron keywords técnicas más alineadas con vacantes reales: HTML5, CSS3, JavaScript, React, Node.js, Java, C# / .NET, APIs REST, SQL.
- Se actualizó el texto de presentación para destacar la formación como egresado de **Ingeniería en Sistemas Computacionales**.
- Se mejoró el panel tipo **Developer Command Center** para mostrar capacidades técnicas por área: Lenguajes, Frontend, Backend, Bases de datos, Automatización e integración.
- Se actualizó también el carrusel mobile del Hero para incluir una visión más completa del perfil técnico.

### Actualización de Stack Tecnológico
- Se rediseñó la sección de Stack con una estructura visual tipo **Logo Cloud + categorías compactas**.
- Se agregaron lenguajes y tecnologías solicitadas comúnmente en vacantes junior: Java, C#, C, C++, Python, HTML5, CSS3, SQL.
- Se reorganizó el stack en categorías más claras: Lenguajes, Frontend, Backend, Bases de datos, Deploy & Tools, Desktop / Mobile.
- Se mantuvo el enfoque principal en tecnologías aplicadas a proyectos reales: React, JavaScript, Node.js, APIs REST, SQLite, Firebase, Git/GitHub, Vercel, Hostinger, Automatización.
- Se agregó una sección de aplicación práctica para conectar el stack con proyectos reales: Hotel San Carlos POS, SapiensAds AI, Desarrollo Web Corporativo.

### Mejora de Contacto
- Se rediseñó la sección Contact para que sea más limpia y directa.
- Se eliminó el botón duplicado del CV dentro de Contact y Footer, dejando el CV únicamente en la Navbar.
- Se actualizó el texto principal para evitar encasillar el perfil solo en Backend/Fullstack: *"Abierto a oportunidades donde pueda construir soluciones digitales."*
- Se agregó mención explícita de la formación en **Ingeniería en Sistemas Computacionales**.
- Se mantuvieron acciones claras: enviar correo, ver GitHub, ver Indeed, ver teléfono y ubicación.

### Ajustes en Footer
- Se simplificó el Footer para evitar repetición de accesos.
- Se conservaron enlaces esenciales: GitHub, Indeed, Correo.
- Se mantuvo el texto: *Built with React, Vite & Tailwind CSS · 2026*.

### Estado actual del proyecto
Las secciones Hero, Stack, Contact y Footer fueron actualizadas para alinear mejor el portafolio con vacantes de desarrollo web, software, backend, frontend y fullstack junior.
