# Edgar Rodriguez Portfolio

Portafolio profesional de Edgar Rodríguez, **Full Stack Developer / Software Developer Jr**, construido con React, Vite, Tailwind CSS y Framer Motion.

## Objetivo

Presentar mi perfil profesional como **Ingeniero en Sistemas Computacionales** con más de 2 años de experiencia práctica desarrollando software, aplicaciones web, sistemas internos, integraciones, automatización de procesos y soluciones tecnológicas orientadas al negocio.

El portafolio está diseñado para mostrar experiencia real, stack técnico, proyectos aplicados y una línea visual **dark premium** con acentos índigo/violeta, glass UI, bordes suaves, fondos con degradados sutiles y componentes interactivos.

## Proyectos Destacados

### Hotel San Carlos POS

Sistema POS de escritorio desarrollado para operación hotelera, con persistencia local y flujo funcional para gestión de productos, ventas y operación diaria.

**Stack:** Electron, Node.js, SQLite, JavaScript, HTML, CSS.

### SapiensAds AI

Plataforma web orientada a operación digital, gestión de datos, automatización e integración de herramientas para flujos internos.

**Stack:** React, Firebase, APIs REST, JavaScript, Tailwind CSS.

### Desarrollo Web Corporativo

Desarrollo y publicación de sitios web corporativos para presencia digital, comunicación de servicios y generación de oportunidades comerciales.

**Stack:** React, HTML5, CSS3, JavaScript, Vercel, Hostinger.
